🚀 درباره پروژه (About)
پروژه Operation Eclipse یک بازی مهیج و مدرن است که با ترکیبی از تکنولوژی‌های وب (HTML5, CSS3, JavaScript) در سمت فرانت‌اند و پایتون در سمت بک‌اند توسعه یافته است. هدف این پروژه ارائه یک تجربه کاربری روان، تعاملی و جذاب است.
---
🛠️ تکنولوژی‌های استفاده‌شده (Tech Stack)
Frontend: HTML5, CSS3, JavaScript (ES6+)
Backend: Python (FastAPI / Standard Server Logic)
Automation & Scripts: Batch Files (`.bat`) برای راه‌اندازی و بیلد آسان
---
📂 ساختار پروژه (Project Structure)
```text
Operation-Eclipse/
│
├── backend/            # منطق سمت سرور و کدهای پایتون
│   └── main.py
│
├── frontend/           # رابط کاربری و استایل‌ها
│   ├── index.html
│   ├── style.css
│   └── game.js
│
├── install.bat         # اسکریپت نصب خودکار وابستگی‌ها
├── run_game.bat        # اسکریپت اجرای سریع بازی
├── build_exe.bat       # اسکریپت ساخت فایل اجرایی (.exe)
└── requirements.txt    # پکیج‌ها و کتابخانه‌های پایتون
```

⚙️ راهنمای نصب و اجرا (Getting Started)
برای اجرای پروژه روی سیستم خود، مراحل زیر را دنبال کنید:
کلون کردن مخزن:
```bash
   git clone https://github.com/YOUR_USERNAME/Operation-Eclipse.git
   cd Operation-Eclipse
   ```
نصب وابستگی‌ها:
کافیست روی فایل زیر دو بار کلیک کنید یا آن را در ترمینال اجرا نمایید:
```cmd
   install.bat
   ```
اجرای بازی:
برای اجرای بازی از اسکریپت زیر استفاده کنید:
```cmd
   run_game.bat
   ```
